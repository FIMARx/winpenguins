2.1 (Next-Level Personality, Toys, SmoothHD & Ambient Polish)
  - Added 240 Hz Direct2D Matrix3x2 visual rotation, tumble spin, and landing/hop squash-and-stretch springs
  - Added soft Direct2D ground-aware contact ellipses beneath airborne and grounded penguins
  - Added penguin-to-penguin head/umbrella bounces, brief walker greetings, and playful belly slides
  - Added Cursor Perch (penguins hop onto a stationary cursor and fling off with momentum on a fast mouse shake)
  - Added interactive Desktop Toys tray submenu (Fish Snacks, Trampolines, and Twin Portals that work across monitors)
  - Added optional falling Snowflakes (Let It Snow) that cap windows/floors and scatter under passing penguins
  - Added WASAPI peak-meter audio detection for music-reactive penguin dancing (Dance to Music)
  - Added Windows Presentation/Focus Assist auto-pause, recording-process auto-pause, and Session Lock zero-GPU sleep
  - Added built-in SmoothHD theme (EPX/Scale2x 64x64 texture upscaling preserving crisp 32x32 logical footprints)
  - Added animated GIF and Aseprite JSON theme importer (plus drag-and-drop import) and live animated theme preview card in Options
  - Upgraded Options & About dialogs to native-style Windows 11 Fluent UI (Dark/Light live sync, pill switches, accent sliders, Fluent ComboBoxes, Mood Presets & instant live preview)
  - Added mouse grab/drag/remove for Desktop Toys, procedural Direct2D micro-emotes (Heart, Music, Alert), right-click penguin/toy context menus, and 240Hz fish-seeking fix
  - Added automatic DXGI/Direct2D device-lost GPU pipeline recovery across sleep-wake, driver updates & monitor docks
  - Added GitHub Actions CI/Release workflow (.github/workflows/ci-release.yml)

2.0 (Modern Windows 11 Rewrite)
  * Complete modern .NET 10 (net10.0-windows) rewrite replacing legacy VS2012 C++/MFC and Winmon.dll
  - Replaced broken SysListView32 GetDC/BitBlt drawing with hardware-accelerated Direct2D + DirectComposition per-monitor GPU overlays (120/240 Hz high-res waitable timer, configurable 60/120/240 FPS)
  - Replaced Winmon.dll global hooks with lightweight background-polled SetWinEventHook (foreground/move-size/minimize only) + DWMWA_CLOAKED + DWMWA_EXTENDED_FRAME_BOUNDS + IsZoomed
  - Added Per-Monitor V2 DPI awareness with automatic per-monitor mixed-DPI scaling (Auto, 1x, 1.5x, 2x, 3x)
  - Added natural motion: sub-pixel float visual interpolation, corrected right-facing sprite row order, per-penguin speed variance, idle pauses/glances, umbrella parachute spawns & mid-air saves
  - Added interactive mouse controls (click to hop & quack, grab/drag/throw across monitors) with dynamic click-through pass-through elsewhere
  - Added custom 32-bit transparent PNG theme packs (theme.json discovery + 1-click SampleCustom export)
  - Added 0-100% WAV PCM volume scaling and wired action sounds (boom, eep, quack + custom WAV)
  - Added multi-monitor roaming, Above Windows vs Desktop Only layer modes, per-process collision exclusions, fullscreen auto-hide, Battery Saver auto-pause, global pause/hide hotkey (Ctrl+Alt+P), scatter, and bomber exit
  - Added JSON settings persistence (%AppData%\WinPenguins\settings.json), 3-tab Options UI, SingleFile publish profile, and expanded xUnit test suite
